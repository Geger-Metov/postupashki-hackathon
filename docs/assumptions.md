# Assumptions

1. **Один `(student_id, timestamp)` = один заказ.**
   Несколько строк с одинаковыми `student_id` и `timestamp` объединяются в один заказ. Это необходимо, потому что отдельного идентификатора заказа в исходном `base.xlsx` нет.

2. **Пакет = 2+ курса в одном заказе.**
   Признак `is_bundle = true` выставляется при `items_count >= 2`. Это операционное определение для анализа; оно не утверждает, что каждая такая покупка была коммерчески оформлена как пакет. В результате получено **153 пакетных заказа**.

3. **`amount` суммируется по заказу.**
   Для выручки заказа и среднего чека используется сумма `amount` всех строк заказа. Выручку нельзя интерпретировать только по отдельным строкам, если несколько строк относятся к одному заказу.

4. **Первый заказ в доступной истории не считается повторным.**
   `is_repeat = false` для первого заказа конкретного `student_id`; последующие заказы получают `is_repeat = true`. Поэтому **22 повторных заказа** — это число повторных заказов внутри периода наблюдения, а не обязательно число покупателей с исторически повторной покупкой.

5. **История до 4 августа отсутствует.**
   Нельзя установить, был ли заказ 04.08.2026 первой покупкой человека в принципе. Повторность определяется только относительно доступной истории.

6. **Исходные суммы не исправляются по предположению.**
   Подозрительно низкие, высокие или нестандартные суммы не удаляются и не заменяются. Для анализа они остаются частью фактической выручки.

7. **Реальные маркетинговые касания исторически не восстановимы полностью.**
   В исходных продажах нет полного журнала кликов, переходов, лидов, рекламных размещений и их стоимости.

8. **Синтетические данные явно отделены от фактических продаж.**
   `ad_registry.csv` и `touches.csv` используются как synthetic-слой для прототипирования и не должны интерпретироваться как реальные исторические рекламные касания покупателей из `base.xlsx`.

9. **Attribution window = 7 дней.**
   Для прототипа атрибуции касания учитываются в течение 7 дней до покупки. Это рабочее допущение, которое должно быть проверено на реальных данных и может быть изменено.

10. **ROMI на синтетике — оценка, а не исторический факт.**
    Реальный исторический ROMI нельзя корректно посчитать без достоверных данных о затратах и связи рекламных размещений с покупками.
