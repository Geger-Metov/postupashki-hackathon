# Assumptions

1. **Один timestamp = один заказ.**
   Несколько курсов в одну секунду — это пакет, а не разные заказы.

2. **Пакет = 2+ курса в одном заказе.**
   Сумма по заказу — это выручка за весь пакет.

3. **amount суммируется по заказу.**
   Нельзя считать выручку по строкам, только по заказам.

4. **История до 4 августа отсутствует.**
   Нельзя восстановить, что было раньше, и делать выводы о динамике.

5. **Реальные касания не восстановимы.**
   Нет журнала кликов, переходов, лидов, рекламных размещений.

6. **Синтетические данные помечены.**
   `ad_registry.csv` и `touches.csv` — synthetic. Явно указываем в README.

7. **Attribution window = 7 дней.**
   Касания учитываем за 7 дней до покупки. Обоснование: типичный цикл решения о покупке курса.

8. **ROMI на синтетике — оценка, не факт.**
   Реальный ROMI нельзя посчитать без cost и placement.
